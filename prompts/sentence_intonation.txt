INTRODUCTION

You are contributing to a benchmark designed to evaluate audio-language models on their ability to understand how something is spoken, not just what is said.
The benchmark consists of ambiguity-resolution tasks that require models to use prosodic cues in a target sentence to choose the correct follow-up among three plausible options.
A text-only model should find all follow-ups equally likely, while an audio-aware model should be able to disambiguate based on sentence-level intonation patterns (e.g., rising, falling, or marked contours).

CATEGORY CONTEXT

Category: Sentence Intonation

Task Description: The interpretation of the sentence depends on its overall intonation contour, especially toward the sentence-final region. A rising pitch may signal a question or uncertainty, a falling pitch may signal a statement or finality, and a marked pattern (e.g., rise-fall, flat, exaggerated) may convey sarcasm, surprise, disbelief, or emotion.

Setting: <<SETTING>>
(The conversational scenario in which all sentences should sound natural. Examples: casual conversation, doctor’s office, legal hearing, team meeting, family dinner.)

REQUIREMENTS FOR THIS TEST CASE
1. Input Sentence

Length: 4–12 words

Must be ambiguous in intent or function without intonation

Must allow for at least three different interpretations, depending on the final pitch contour

Should be plausible and natural in the given setting

Avoid named entities unless necessary for context

2. Follow-up Sentences (3 total)

Length: 5–12 words each

Each must be textually plausible given the input

Each must only make sense under one intonation contour (rising / falling / expressive)

All follow-ups should appear equally likely to a text-only model

3. Prosody Instructions

For each option:

Provide input prosody instruction: how to read the input to trigger the intended intonation contour

Provide follow-up prosody instruction: how the follow-up should be spoken to match and support that intonation pattern

Use imperative style (e.g., “Use a rising pitch at the end...”)

Reference pitch, pacing, contour shape, and communicative effect

4. Explanations

For each follow-up, explain why that intonation pattern makes it the correct continuation

Use a consistent formula:

"Explain why using a <<INTONATION_TYPE>> intonation makes this follow-up the correct continuation."

5. Voice Assignment

Set "different_voices": true if the scenario benefits from having different speakers (e.g., questions and answers)

Set "different_voices": false if a single speaker is more natural
