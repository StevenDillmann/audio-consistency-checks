✅ VOICE QUALITY AND EFFORT — BENCHMARK PROMPT TEMPLATE
INTRODUCTION

You are contributing to a benchmark designed to evaluate audio-language models on their ability to understand how something is spoken, not just what is said.
The benchmark consists of ambiguity-resolution tasks that require models to use prosodic cues in a target sentence to choose the correct follow-up among three plausible options.
A text-only model should find all follow-ups equally likely, while an audio-aware model should be able to disambiguate based on nonverbal vocal characteristics — such as whispering, shouting, monotone delivery, breathiness, or vocal tension.

CATEGORY CONTEXT

Category: Voice Quality and Effort

Task Description: The interpretation of the sentence depends on how it is vocally delivered — whether it’s whispered, shouted, flat, tense, airy, etc. These vocal features express speaker state, emotion, or intent, and cannot be derived from the text alone.

Setting: <<SETTING>>
(The real-world context in which the sentence is spoken — e.g., tense confrontation, therapy session, stage performance, phone call.)

REQUIREMENTS FOR THIS TEST CASE
1. Input Sentence

Length: 4–12 words

The words must remain lexically identical across all readings

The meaning must change depending on vocal delivery, not pitch contour or emphasis alone

The sentence must support at least three distinct interpretations via vocal quality or vocal effort

2. Follow-up Sentences (3 total)

Length: 5–12 words each

Each must be textually plausible but semantically distinct

Each must correspond to one specific vocal delivery

None should be universally valid: each only works with its matching vocal quality cue

3. Prosody Instructions

For each option:

Provide input prosody instruction: how to vocally deliver the input sentence to make that option correct

Provide follow-up prosody instruction: how the continuation should be delivered to match or respond to that quality

Use imperative style (e.g., “Whisper the entire sentence softly…”)

Reference loudness, vocal tension, monotonicity, breath support, etc.

4. Explanations

For each option:

Explain why that specific vocal delivery makes the continuation correct

Use this standardized structure:

"Explain why delivering the input with a <<VOICE_QUALITY>> voice makes this follow-up the correct continuation."

5. Voice Assignment

Set "conversation_type": "dialogue" if the follow-up is naturally a reply from another speaker

Set "conversation_type": "monologue" if the original speaker would likely continue
